## 2. 主路径演示:C + B 自修复闭环

### 2a. 快速演示(rule 模式,~45s,确定性决策)

```bash
eda self-heal \
    --rtl data/examples/counter_bitwidth/rtl.v \
    --tb  data/examples/counter_bitwidth/tb.v \
    --top-module counter \
    --goal "pass all tests" \
    --mode rule
```
→ stdout 打印 `runs/<run_id>/report.md`,退出码 0=ok。counter_bitwidth(reg [3:0]→[7:0])经 A 诊断根因 + B GLM patch,2 轮收敛 all_pass。

### 2b. agentic 充分性演示(LLM 模式,默认,~500s)

```bash
eda self-heal \
    --rtl data/examples/counter_bitwidth/rtl.v \
    --tb  data/examples/counter_bitwidth/tb.v \
    --top-module counter \
    --goal "pass all tests"
```
CPlanner ReAct LLM 决策每步 tool + B 内 LLM patch,展示 agentic 编排(完赛奖第 4 条)。

> **何时用哪个**:实验/快速验证用 `--mode rule`(确定性,44-87s/bug);演示 agentic 充分性用默认 LLM 模式。

## 3. A 诊断器单点演示(不修复,~10s)

```bash
eda diagnose --rtl data/examples/counter_syntax/rtl.v --tb data/examples/counter_syntax/tb.v
```
→ 诊断报告 `runs/<run_id>/diagnose/report.md`,parsed 含 root_causes / confidence / needs_rtl_patch / fix_hints(13 字段)。

## 4. 渲染已有 run 的报告

```bash
eda report <run_id>    # 打印 runs/<run_id>/report.md
```

## 5. 全量 8 bug 实验证据(评审)

见 `runs/eval_snapshot/verdict.md`:**S1 硬门槛全过 + 良好线(6/6 healable all_pass,overall 0.875)**。

| fault_type | pass_rate | 明细 |
|---|---|---|
| bitwidth | 2/2 = 1.0 | counter_bitwidth + adder_pipe_bitwidth |
| syntax | 2/2 = 1.0 | counter_syntax + adder_pipe_syntax |
| timing_reset | 2/2 = 1.0 | counter_reset + tiny_fsm_reset(bonus) |
| comb_logic | 1/2 = 0.5 | adder_pipe_comb + tiny_fsm_comb(healable=false 合规失败) |

- `experiment_summary.json`:by_fault_type 聚合
- `manifests/<design_id>.json`:8 bug 的 experiment_manifest(14 字段)
- `reports/<design_id>.report.md`:B 自修复 trajectory
- `fixed_rtl/<design_id>.rtl.v`:GLM 修复结果

复现全量实验:
```bash
# 单 bug(传 extra 使 manifest 字段完整)
python scripts/run_self_heal.py --rtl data/examples/counter_bitwidth/rtl.v \
    --tb data/examples/counter_bitwidth/tb.v --top-module counter \
    --design-id counter_bitwidth --fault-type bitwidth --mode rule
# 聚合
python scripts/summarize_eval.py --runs-dir runs --out experiment_summary.json
```
